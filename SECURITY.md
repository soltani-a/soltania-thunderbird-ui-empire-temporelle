# Sécurité

Empire temporelle est un thème statique Thunderbird. Le paquet contient un manifeste, une image SVG locale et la licence. Il n’exécute aucun script, ne demande aucune permission et ne lit ni messages ni carnet d’adresses.

La branche `main` est la référence pour les corrections. Aucun délai de réponse ou de correction n’est garanti.

## Signalement

Ne publiez pas de secrets ou de détails d’exploitation sensibles dans les issues. Utilisez le signalement privé GitHub s’il est disponible dans l’onglet Security. Sinon, ouvrez une issue demandant un canal privé, sans détails sensibles. Les problèmes de couleurs ou de lisibilité peuvent être signalés publiquement.

## Distribution

Téléchargez le `.xpi` depuis les Releases de ce dépôt. Thunderbird n’impose pas de signature Mozilla. Le fichier `SHA256SUMS` permet de comparer l’intégrité des téléchargements ; il ne constitue pas une signature cryptographique de l’auteur.
