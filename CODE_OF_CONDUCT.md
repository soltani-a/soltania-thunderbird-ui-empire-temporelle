# Code de conduite

Les échanges dans ce projet doivent rester respectueux, constructifs et centrés sur les idées et le travail.

- Accueillir les questions et les contributions de tous les niveaux.
- Expliquer les désaccords sans attaque personnelle.
- Respecter la vie privée et ne pas publier de données personnelles sans consentement.
- Éviter les propos discriminatoires, le harcèlement et les contenus menaçants.

Les responsables du dépôt peuvent modérer les contributions et les discussions qui ne respectent pas ces règles. Utilisez les outils de signalement GitHub lorsqu’un échange pose problème.
